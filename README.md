# 边缘行者战役车卡器

一个面向赛博朋克战役框架「边缘行者」的专属车卡器。

## 主要用途

- 编辑角色车卡。
- 管理多个角色存档。
- 打印角色卡，或导出为 HTML / PDF。
- 从导出的 HTML 文件重新导入角色。
- 生成适配 SealDice 的导出文本。
- 导入、启停、删除自定义卡包。
- 用可视化编辑器维护卡包内容。

## 主要页面

- `/`：主车卡工作台。
- `/card-editor`：卡包编辑器。
- `/card-manager`：卡包管理页。

## 使用

本地开发：

```bash
pnpm install
pnpm dev
```
